Topic 1 • Variables

What Is a Variable?

المتغير — صندوق لتخزين البيانات في الذاكرة
The Box Analogy

A variable is a named container in the computer's memory used to store a value.

المتغير (Variable) ببساطة هو مكان مسمى ومحجوز داخل ذاكرة الكمبيوتر (RAM) عشان نحفظ فيه معلومة أو قيمة نحتاجها ونرجع نستخدمها أو نعدلها لاحقاً.
  • 📦
    The Label: The identifier we use to refer to the container (e.g. score).
  • 💎
    The Value: The data sitting inside the container (e.g. 100).
Topic 1 • Variables

Variable Declaration

الإعلان عن المتغير — حجز الصندوق في الذاكرة
Syntax Anatomy

Declaration means telling the computer to create and name a new space in memory.

الإعلان (Declaration) هو خطوة حجز المكان بالاسم، كأنك اشتريت صندوق جديد وكتبت عليه الاسم، لكنك لسه محطتش جواه حاجة.
let Keyword: Tells the computer "prepare a new variable".
score Identifier: The unique name of this variable container.
; Semicolon: Ends the instruction statement.
JavaScript
// Declaration (الحجز فقط)
let score;
💡 Note: At this precise moment, score exists in memory, but has no assigned value yet (it is undefined).
Topic 1 • Variables

Assignment

التخصيص — تخزين القيمة داخل الصندوق
Storage Operation

Assignment is the act of storing a specific value into an existing variable container.

التخصيص (Assignment) يعني أخذ القيمة الموجودة على اليمين ووضعها داخل المتغير الموجود على الشمال باستخدام علامة التخصيص =.
  • ←
    Direction matters: Value flows from right to left!
  • =
    The = operator here means "store into", not mathematical equality.
Topic 1 • Variables

Declaration + Assignment

طريقتان للكتابة — نفس النتيجة في الذاكرة
Syntax Comparison
Approach A: Two Steps

Declare First, Assign Later

let score;        // Step 1: Declare
score = 100;      // Step 2: Assign

Useful when you do not know the value yet (e.g. waiting for user input or an if condition).

Approach B: One Step (Recommended)

Combined Initialization

let score = 100;  // Combined!

Declares the container and immediately fills it with a value. Cleaner, shorter, and standard practice.

Topic 1 • Variables

Reassignment

إعادة التعيين — استبدال القيمة القديمة بالجديدة
Overwriting Memory

A variable can change its stored value at any time. The new value overwrites the old value completely.

المتغير سمي "متغيراً" لأنه يقبل تغيير محتواه! لما بنخزن قيمة جديدة، القيمة القديمة بتتمسح تماماً ويقعد مكانها الرقم الجديد.
⚠️ Rule: Do NOT write let again when reassigning an existing variable!
Topic 1 • Variables

Increment & Decrement

الزيادة والنقصان — العداد الرقمي (score++ و score--)
Shorthand Operators

Programmers modify numbers by 1 so frequently that special shorthand operators exist:

Increment: adds 1
score = score + 1;
score--
Decrement: subtracts 1

أداتي الزيادة ++ والنقصان -- من أهم الأدوات اللي هنستخدمها في حلقات التكرار (Loops) لعد الدورات.

lives--;

What is the output?

2

`lives` decreases by 1 from 3 to 2.

Variable Naming Rules

قواعد وأسلوب تسمية المتغيرات (Best Practices)
Clean Code

Code is read by humans far more often than it is written. Clean variable names prevent costly bugs!

  • ✓
    Meaningful & Descriptive: Explain what is inside without guessing.
  • ✕
    No Spaces Allowed: first name is invalid syntax!
  • camelCase
    Standard Convention: Start lowercase, capitalize subsequent words (e.g. studentScore).
💡 قاعدة ذهبية: لو خفيت قيمة المتغير، هل الاسم لوحده يخليك تفهم الصندوق ده فيه إيه؟

What does `x` mean? What kind of `data`? Unreadable.

✓ CLEAR & PROFESSIONAL
let studentAge = 16;
let studentName = "Omar";
let birthCity = "Cairo";

Instant clarity for teachers, teammates, and exams!

The IF Statement

تركيب جملة IF الشرطية البسيطة
Syntax Blueprint

The basic structure of decision making in code:

if Keyword: Signals the start of a condition check.
( condition ) The Question: Must evaluate to true or false.
{ process; } The Process Block: Executes ONLY if the condition is true.

}
Topic 4 • Conditions

Anatomy Breakdown
Concrete Example
if (score >= 50) {
    console.log("Pass");

الشرط هو الفحص المنطقي: "هل الدرجة أكبر من أو تساوي 50؟" — العملية هي النتيجة: "اطبع Pass".
PART 1: THE CONDITION
score >= 50

The gatekeeper question. Result is always Boolean (true or false).

PART 2: THE PROCESS
console.log("Pass");

The action that only unlocks when the gatekeeper says TRUE.

Topic 5 • For Loops

Why Loops?

لماذا نحتاج التكرار؟ تجنب تكرار كتابة السطور
Automation

Imagine your program needs to print "Hello" 10 times. Or 1,000 times!

لو طلب منك تطبع كلمة "Hello" عشر مرات، هل هتكتب console.log("Hello"); عشر مرات تحت بعض؟ طب لو 1000 مرة؟!

Copy-pasting lines makes code rigid, messy, and error-prone. A Loop allows you to write the instruction once and tell the computer how many times to repeat it.

❌ TEDIOUS REPETITION
console.log("Hello");
console.log("Hello");
console.log("Hello");
console.log("Hello");
console.log("Hello");
// 5 more identical lines...
✓ CLEAN LOOP (3 LINES)
for (let i = 0; i < 10; i++) {
  console.log("Hello");
}

Clean, scalable, and professional.

Topic 5 • For Loops

The FOR Loop Structure

تشريح حلقة FOR — الأجزاء الأربعة الأساسية
Syntax Blueprint

A standard for loop coordinates 4 distinct components separated by semicolons:

1. let i = 0 Initialization: Creates the counter variable (runs once).
2. i < 5 Condition: Checked before each spin; loop continues while true.
3. i++ Update: Increments counter after each spin.
4. { process } Process: The instructions repeated each iteration.
FOR Loop Syntax
for (let i = 0; i < 5; i++) {
    console.log(i);
}
Topic 5 • For Loops

Loop Execution Cycle

دورة حياة اللوب — خطوات التنفيذ خطوة بخطوة
Flowchart Cycle

Notice the exact sequence the engine follows:

  1. Initialize: let i = 0 (happens once at start).
  2. Check Condition: Is i < 5?
  3. If True: Execute the body code inside { }.
  4. Update: Run i++ to advance the counter.
  5. Repeat: Check condition again.
  6. Exit: When condition becomes false, break out!
أهم ملاحظة: زيادة العداد i++ بتحصل بعد تنفيذ الكود الداخلي مش قبله!

Topic 6 • Functions

Defining vs Calling a Function

الفرق الحاسم: تعريف الدالة مقابل استدعائها وتشغيلها
Crucial Distinction

Writing a function does NOT run it. You must explicitly call it!

صناعة الماكينة (Definition) حاجة، والضغط على زر التشغيل (Call / Invoke) حاجة تانية خالص! لو كتبت دالة 100 سطر ومستدعتهاش، ولا سطر هيتنفذ!
  • 🏭
    Definition: Teaching the computer the recipe once.
  • ▶
    Call: Triggering the recipe with greet();.
1. THE DEFINITION (CREATION)
function greet() {
  console.log("Hello");
}

Stored in memory. Silent until called.

2. THE CALL (EXECUTION)
greet();

Presses the start button! "Hello" is printed.

Topic 6 • Functions

Function with Input (Parameters)

الدوال بمدخلات — جعل الدالة مرنة وقابلة للتخصيص
Parameters & Arguments

Passing data into a function makes it infinitely more useful and flexible.

بدل ما نعمل دالة تسلم على اسم ثابت، بنمرر لها "متغير مدخل" (Parameter) يرحب بأي اسم نبعته لها في كل استدعاء! 
function greet(name) {
    console.log("Hello " + name);
}

greet("Omar");  // Prints: Hello Omar
greet("Nour");  // Prints: Hello Nour
THE HANDOFF IN MEMORY
Caller passes: "Omar"
⬇️
Parameter receives: name = "Omar"

One function handles hundreds of different students effortlessly!

Common Beginner Mistakes Checklist

أشهر 9 أخطاء يقع فيها الطلاب — احذر هذه المطبات!
Checklist
1. = vs ==
Using = (assignment) inside an if condition instead of == (comparison).
2. Forgetting Quotes
Writing let name = Omar; without quotes causes JavaScript to search for a variable named Omar!
3. "100 + 200" Trap
Thinking text in quotes will calculate mathematically. Quotes freeze it as literal text!
4. Forgetting i++
Leaving out the loop counter increment creates an infinite loop that crashes the browser.
5. Defining Without Calling
Writing a function but wondering why nothing happened because you forgot to write myFunc();!
6. Semicolon After IF
Accidentally writing if (x > 5); { ... } which terminates the check prematurely!
Quick Fire

Rapid Review: Can You Answer?

مراجعة خاطفة — 10 أسئلة سريعة (اضغط للكشف)
Interactive Game
1. What is a variable? A named memory container storing a value.
2. What does assignment (=) do? Stores the right-hand value into the left variable.
3. What is a String? Text wrapped inside quotation marks.
4. What are the two Boolean values? true and false.
5. What does console.log() do? Prints output to the developer console.
6. What symbol starts a single-line comment? // (double forward slash).
7. When does the process inside an IF run? When the condition evaluates to true.
8. When does an ELSE block run? When the preceding IF condition is false.
9. What is a for loop used for? Repeating instructions without code duplication.
10. What is a function? A reusable packaged machine of code.

3. FINAL PREDICTION CHALLENGE
let score = 5;

for (let i = 0; i < 3; i++) {
    score++;
}

console.log(score);
✓ Final Output:
8

`score` starts at 5. The loop runs 3 times (i = 0, 1, 2), incrementing `score` each time: 5 → 6 → 7 → 8!
