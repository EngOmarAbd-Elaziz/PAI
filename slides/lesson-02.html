Topic 1 • Functions

What is a Function?

ما هي الدالة ولماذا نستخدمها؟
Concept

A Function is a named block of reusable code designed to perform a specific task.

في عالم البرمجة، لدينا مبدأ أساسي يسمى DRY (Don't Repeat Yourself). إذا وجدت نفسك تكتب نفس السطور البرمجية مراراً وتكراراً، فأنت بحاجة لإنشاء Function! تجمع فيها هذه السطور وتعطيها إسماً، ثم تكتفي بمناداتها (Call) متى احتجتها.
  • 1
    Define once: Build the machine logic in one place.
  • 2
    Call anywhere: Execute it anytime without rewriting the code.
  • 3
    Easy to fix: If there is a bug, you fix it in one place!
THE SYNTAX ANATOMY
// 1. Function Definition (Building the Machine)
function sum(a, b) {
    return a + b;
}

// 2. Function Call (Using the Machine)
let result = sum(10, 20);
console.log(result); // Prints 30
💡 بدون الخطوة الثانية (Call)، الماكينة موجودة لكنها مطفأة ولن تنفذ أي شيء!
Topic 1 • Functions

Parameter vs Argument

الفرق الجوهري: المعاملات مقابل القيم الحقيقية
Crucial Terminology

Many beginners confuse these two terms. Let's make it unforgettable using a real-world analogy!

كيف تفرق بين الـ Parameter والـ Argument؟ تخيل استمارة التقديم في المدرسة. الورقة المطبوعة بها خانات فارغة (الاسم، السن). هذه الخانات هي الـ Parameters. أما بياناتك الحقيقية التي تكتبها بالقلم، فهي الـ Arguments!
📥
Parameter (المعامل)
The placeholder variable written when DEFINING the function.
function greet(name)
مثل: الفراغات المطبوعة في الاستمارة (أماكن محجوزة لبيانات ستأتي لاحقاً).
🎯
Argument (القيمة)
The actual value passed when CALLING the function.
greet("Omar")
مثل: اسمك الحقيقي الذي كتبته بالقلم داخل الخانة لملء الفراغ!
Topic 1 • Application

Real Example: Swimming Team

تطبيق عملي: حساب أزمنة فريق السباحة
Code Analysis

Let's build a function that calculates the total time for a relay race by adding the freestyle and breaststroke times.

في هذا المثال، سننشئ دالة تستقبل زمن سباحتين مختلفتين وتجمعهما. الجميل هنا أننا نستطيع استخدام نفس الدالة لفرق مختلفة (Reusability)!

Topic 1 • Mechanics

Return & Execution Flow

إرجاع النتيجة وتدفق التنفيذ خطوة بخطوة
Flow Tracing

Step-by-Step Execution

الكمبيوتر لا ينفذ الكود بشكل عشوائي، بل يتبع خريطة تدفق دقيقة جداً. إليك ما يحدث خلف الكواليس عند تشغيل كود السباحة:

  1. Definition: The computer reads the function sum() { ... } block and saves it in memory. It does NOT run it yet.
  2. Call Triggered: When it reaches sum(39.5, 60.5), it jumps to the function.
  3. Argument Mapping: 39.5 is poured into the freestyle parameter, and 60.5 into breaststroke.
  4. Calculation: result = 39.5 + 60.5 (result becomes 100).
  5. The Return: The return result; command actively shoots the number 100 out of the function, back to where it was called.
  6. Storage: The returned 100 is assigned into the variable teamRed.

🚨 CRITICAL RULE: Forgetting `return`

إذا نسيت كتابة كلمة return، الدالة ستحسب الجمع في الذاكرة، لكنها لن تخرجه لك! سيعتبر الكمبيوتر أن الدالة لم ترجع شيئاً وسيكون الناتج undefined. الـ return هو الباب الذي تخرج منه النتيجة!

Topic 1 • Expansion

Adding More Parameters

التوسع: 3 معاملات، وفرق متعددة
Reusability

Functions are not limited to 2 parameters! You can add as many as your logic requires. Let's add backstroke.

يمكن للدالة أن تستقبل 3 معطيات أو أكثر. سنقوم الآن بترقية الدالة لحساب أزمنة ثلاثة سباحين. ونرى سحر البرمجة (Reusability) باستدعاء نفس الدالة لثلاثة فرق مختلفة!
🛑 THINK
What happens if we pass 2 arguments to a function expecting 3?

المعامل الثالث سيكون undefined، وعند محاولة جمعه مع أرقام، ستنهار المعادلة ويصبح الناتج NaN (Not a Number)! يجب أن يتطابق عدد القيم مع عدد المعاملات قدر الإمكان.

JavaScript — 3 Parameters
function sum(freestyle, breaststroke, backstroke) {
  let time = freestyle + breaststroke + backstroke;
  return time;
}

// Using the SAME machine for 3 different teams!
let teamRed = sum(39.5, 60.5, 58.5);   // 158.5
let teamBlue = sum(40, 62, 58);       // 160
let teamGreen = sum(41, 59.5, 60);    // 160.5
Topic 1 • Dynamic Input

Variables as Arguments & Math.min

استخدام المتغيرات كمدخلات، والدالة الجاهزة Math.min
Advanced Techniques

You don't have to pass raw numbers. Pass variables instead!

لكي نجعل برنامجنا ديناميكياً 100%، نقوم بتمرير أسماء المتغيرات إلى الدوال. الكمبيوتر سيقرأ ما بداخل المتغير ويمرره. كما نتعرف هنا على دالة جاهزة في اللغة اسمها Math.min() وظيفتها استخراج أصغر رقم من مجموعة أرقام.
❌ STATIC (BAD)
Math.min(158.5, 160, 160.5);
✓ DYNAMIC (PRO)
Math.min(teamRed, teamBlue, ...);
JavaScript — Dynamic Find
// We already have variables from the previous slide!
// teamRed = 158.5, teamBlue = 160, teamGreen = 160.5

// Use Math.min to find the fastest (smallest) time
let fastest = Math.min(teamRed, teamBlue, teamGreen);

// Concatenate text and number
console.log("The fastest time is " + fastest);
Output: The fastest time is 158.5
Topic 2 • Flowcharts

Flowcharts: Drawing Logic

المخططات الانسيابية — هندسة القرارات بصرياً
Visual Planning

A Flowchart is a visual map of a program's logic. We use it to plan BEFORE writing code!

مثلما يرسم المهندس خريطة للمبنى قبل بنائه، يرسم المبرمج خريطة (Flowchart) ليوضح كيف تتدفق البيانات وأين تُتخذ القرارات (هل نذهب يميناً أم يساراً؟).

The 3 Core Shapes

Decision (المُعَيّن)
يمثل سؤال / شرط if. يخرج منه دائماً سهمان: نعم (True) ولا (False).
Process (المستطيل)
يمثل عملية: كود رياضي، طباعة console.log، أو تخزين قيمة.
➔
Arrows (الأسهم)
توضح مسار سريان البرنامج من خطوة لأخرى.

Topic 2 • Critical Pattern

Array + Loop + Condition Pattern

النمط الذهبي: التصفح والبحث بداخل القوائم مع عداد
Crucial Pattern

This combination is one of the most powerful and common patterns in all of software engineering!

تجميع القائمة (Array) مع حلقة التكرار (for...of) مع الشرط (if) مع العداد (count++) يُستخدم لعدّ أو تصفية بيانات تحقق شرطاً معيناً. سنعد هنا المتطوعين الذين أجابوا بـ "Yes".
  1. Start a counter at 0.
  2. Loop over every element in the array one by one.
  3. Ask a question (if condition) for the current element.
  4. If true, increment the counter (count++).
JavaScript — The Counter Pattern
let volunteerList = ["Yes", "No", "Yes", "Yes", "No"];
let count = 0;

for (let day of volunteerList) {
  if (day == "Yes") {
    count++;  // Same as: count = count + 1;
  }
}
console.log(count); // Will print 3
Topic 2 • Advanced Logic

Nested Conditions

الشروط المتداخلة (Nested IF) — القرار المبني على قرار
Deep Branching

A Nested if is an if statement placed inside another if statement.

نستخدمها عندما نحتاج لاتخاذ قرار، ثم نحتاج لاتخاذ قرار "آخر" مبني على نتيجة القرار الأول. (الوصول للشرط الداخلي مستحيل إلا إذا كان الشرط الخارجي صحيحاً).
🛑 CHALLENGE: TRACE THE LOGIC
What is printed if passed = true and score = 80?

Look at the code on the right. Trace it from top to bottom.

✓ Step by step trace:
  1. Is passed == true? Yes! Enter block.
  2. Is score == 100? No! (It's 80). Jump to inner else.
  3. Result: "Congratulations"
JavaScript — Nested IF
// OUTER CONDITION
if (passed == true) {

    // INNER CONDITION (Only checked if passed is true)
    if (score == 100) {
        console.log("Full Mark");
    } else {
        console.log("Congratulations");
    }

} else {
    // Outer False Path
    console.log("Study Harder");
}
