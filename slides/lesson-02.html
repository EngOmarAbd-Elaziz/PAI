Learn how to create reusable functions, pass parameters, and return values. Then visualize logic using Flowcharts.

تعلم كيفية إنشاء دوال قابلة لإعادة الاستخدام، تمرير المتغيرات كمدخلات، وإرجاع القيم. ثم تخطيط المنطق البرمجي باستخدام المخططات الانسيابية.

🎯 What is a Function? (ما هي الدالة؟)

الـ Function (الدالة) هي مجموعة من الأوامر البرمجية (الكود) تم تجميعها معًا وإعطاؤها اسمًا محددًا، لتقوم بتنفيذ مهمة معينة بدلاً من تكرار الكود مراراً وتكراراً.

🚨 Parameter vs Argument

  • Parameter: هو المتغير أو المكان الوهمي الذي نجهزه عند "تعريف" الدالة لتستقبل القيم لاحقاً.
  • Argument: القيمة الحقيقية التي نرسلها للدالة عند "استدعائها".

💡 Execution Flow (تدفق التنفيذ)

  1. Function creation: تعريف الدالة في الذاكرة.
  2. Function call: استدعاء الدالة.
  3. Arguments are passed: إرسال القيم.
  4. Calculation: التنفيذ.
  5. return: إرجاع النتيجة.
  6. Store/Print: استخدام النتيجة.

📐 Flowcharts (المخططات الانسيابية)

المخطط الانسيابي هو رسم بياني يمثل خطوات البرنامج والقرارات المنطقية داخله.

  • المُعَيّن (Diamond): قرار أو شرط (if).
  • المستطيل (Rectangle): عملية أو أمر (Process).
  • الأسهم (Arrows): اتجاه سير البرنامج.
