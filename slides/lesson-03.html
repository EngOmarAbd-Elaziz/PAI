Topic 1 • HTML Review

Headings, Paragraphs & Lists

العناوين، الفقرات، والقوائم
Concept

We use specific Tags in HTML to define different parts of the document.

الـ HTML بيوفرلنا وسوم (Tags) لترتيب الكلام. بنستخدم <h1> للعنوان، و <p> للفقرة، و <ul> مع <li> لإنشاء قوائم نقطية.
  • H
    <h1> to <h6>: Headings from largest to smallest.
  • P
    <p>: Paragraphs for regular text.
  • L
    <ul> & <li>: Unordered lists and list items.
HTML
<h1>My Goals</h1>
<p>I want to learn coding.</p>
<ul>
  <li>Learn HTML</li>
  <li>Learn CSS</li>
</ul>
Topic 2 • Styling

CSS Anatomy & Classes

أجزاء الـ CSS والفئات
Concept

CSS consists of a Selector, a Property, and a Value. We use classes to target specific elements.

أي كود CSS بيتكون من: المُحدد (Selector) عشان نختار العنصر، الخاصية (Property) زي اللون، والقيمة (Value). وبنستخدم الـ Class (وبنكتب قبله نقطة) عشان نحدد عنصر معين بس.
  • S
    Selector: e.g., p or .my-class
  • P
    Property: e.g., color or background-color
  • V
    Value: e.g., red or 20px
CSS
/* Selector { Property: Value; } */
p {
  color: red;
}

/* Class Selector */
.blue-text {
  color: blue;
}
Topic 3 • Inputs

Inputs and Buttons

حقول الإدخال والأزرار
Concept

Use the <input> tag to create interactive fields and buttons for user data.

بنستخدم وسم <input> عشان نعمل أدوات الإدخال. لو كتبنا type="text" هيعمل مربع نص، ولو كتبنا type="button" هيعمل زرار.
HTML
<h1>Survey</h1>
<p>What is your name?</p>
<input type="text">
<input type="button" value="Submit">
Topic 4 • Interactivity

Hover & Transitions

التفاعل والانتقالات الناعمة
Concept

Use :hover to change styles on mouse hover, and transition to make the change smooth.

بنستخدم :hover عشان نغير شكل الزرار لما الماوس يعدي من عليه. وخاصية transition بتخلي التغيير ده يحصل بنعومة بالتدريج.
CSS
.btn {
  background-color: gray;
  /* 1 second transition */
  transition: 1s; 
}

/* When mouse hovers */
.btn:hover {
  background-color: lime;
}
Topic 5 • Box Model

CSS Borders

إضافة الحدود للعناصر
Concept

The border property adds a frame around elements with thickness, style, and color.

خاصية border بتعمل إطار حوالين العنصر. بنحدد فيه 3 حاجات بالترتيب: السُمك (بالبيكسل px)، والنوع (زي solid أو double)، واللون.
CSS
.my-box {
  /* Thickness Type Color */
  border: 5px solid red;
}

.fancy-box {
  border: 10px double blue;
}
