Unit 1 • HTML Review

Headings & Paragraphs

العناوين والفقرات
Concept

We use specific Tags in HTML to define the meaning of our text.

الـ HTML بيوفرلنا وسوم (Tags) لترتيب الكلام. بنستخدم <h1> للعنوان الرئيسي الضخم، و <p> للفقرة العادية. ولازم نقفل الوسم عشان المتصفح يفهم إننا خلصنا.
  • H
    <h1> to <h6>: Headings.
  • P
    <p>: Paragraphs for regular text.
HTML
<h1>My Engineering Goals</h1>

<p>I want to learn coding because it is the language of the future.</p>
Unit 1 • HTML Review

Lists & Images

القوائم والصور
Concept

Lists organize items, while Images make the page visual. The <img> tag is self-closing!

القوائم بتحتاج وسم <ul> يضم جواه عناصر <li>. أما الصور فبنستخدم وسم <img> وهو مختلف لأنه مش محتاج وسم إغلاق، بس لازم نحدد مكان الصورة بخاصية src.
  • L
    <ul> & <li>: Unordered lists and list items.
  • I
    <img>: Uses "src" attribute.
HTML
<!-- Unordered List -->
<ul>
  <li>Learn HTML</li>
  <li>Learn CSS</li>
</ul>

<!-- Image Tag (No closing tag!) -->
<img src="robot.png">
Unit 2 • CSS Anatomy

Selector, Property, Value

تشريح كود الـ CSS
Concept

Every CSS rule needs three things: Who (Selector), What (Property), and the Result (Value).

عشان تدي أمر للـ CSS، لازم تحدد 3 حاجات: المُحدد (أنا بكلم مين؟ مثلاً حرف p)، الخاصية (عايز أغير إيه؟ مثلاً color)، والقيمة (النتيجة إيه؟ مثلاً red).
  • S
    Selector: e.g., p or h1
  • P
    Property: e.g., color
  • V
    Value: e.g., red
CSS
/* Selector { Property: Value; } */
p {
  color: red;
  background-color: yellow;
}

h1 {
  color: blue;
}
Unit 2 • Advanced Selection

Classes & The Span Tag

الفئات الدقيقة ووسم span
Concept

Use a Class to style specific elements. Use <span> to style a single word inside a line.

تخيل عندك 100 كرسي وعايز تلون 5 منهم للـ VIP، الـ Class هو الاستيكر اللي هتحطه عليهم. ووسم span بنستخدمه لو عايزين نلون كلمة واحدة بس جوة سطر من غير ما السطر يتقطع.
HTML + CSS
<p>I love the <span class="sea">sea</span>.</p>

<style>
  /* Notice the dot (.) before the class name! */
  .sea {
    color: blue;
  }
</style>
Unit 3 • Inputs

Forms: Inputs & Buttons

حقول الإدخال والأزرار
Concept

A website without inputs is just a poster. Use the <input> tag to let users interact!

عشان نخلي المستخدم يتفاعل ويدخل بياناته، بنستخدم وسم <input>. الجميل إن الوسم ده بيتغير شكله حسب الـ type. لو text بيعمل مربع، ولو button بيعمل زرار.
  • ⌨️
    Text Box: type="text"
  • 🖱️
    Button: type="button"
HTML
<h1>Login</h1>

<p>Username:</p>
<input type="text">

<!-- value changes the button text -->
<input type="button" value="Submit">
Unit 4 • Text Formatting

Essential CSS Properties

الخصائص الأساسية للتنسيق
Concept

Mastering these 4 properties gives you control over 80% of text styling in any web project.

إتقانك للخصائص الأربعة دي هيديك تحكم كامل في شكل أي نص في موقعك (اللون، الخلفية، الحجم، والسُمك).

Unit 5 • Interactivity

The :hover Pseudo-class

سحر الـ Hover
Concept

Use :hover to change styles ONLY when the mouse pointer is resting on the element.

عشان نحسس المستخدم إن الزرار شغال وتفاعلي، بنستخدم :hover. دي بتخلي الكود يتنفذ (مثلاً يتغير لونه) فقط طول ما الماوس فوق العنصر.
CSS
/* 1. Normal State */
.btn-magic {
  background-color: gray;
  color: white;
}

/* 2. Hover State */
.btn-magic:hover {
  background-color: lime;
  color: black;
}
Unit 6 • Smoothness

Smooth Transitions

نعومة الانتقالات التدريجية
Concept

The transition property slows down CSS changes over a specified time in seconds (s).

تغيير اللون في الـ hover بيحصل فجأة زي الخبطة! عشان نخليه يتغير بنعومة واحترافية، بنستخدم transition وبنحدد الوقت بالثواني (s).
CSS
.btn-smooth {
  background-color: blue;
  
  /* Takes 1 second to change */
  transition: 1s; 
}

.btn-smooth:hover {
  background-color: red;
}
Unit 7 • Box Model

CSS Borders Anatomy

تشريح حدود العناصر
Concept

The border property adds a frame. It requires 3 values: Thickness, Style, and Color.

خاصية border بتعمل إطار حوالين العنصر. لازم نحدد 3 حاجات بالترتيب: السُمك (بالبيكسل)، والنوع (مُصمت solid، أو مزدوج double)، واللون.
CSS
.alert-box {
  /* Thickness Type Color */
  border: 5px solid red;
}

.fancy-frame {
  border: 10px double gold;
}

Common Mistakes

أخطاء شائعة (المطبات)
Concept

Watch out for these beginner traps that cause major bugs in your code!

تجنب هذه الأخطاء الأربعة لتصبح مبرمجاً محترفاً وموفراً للوقت!

Knowledge Check

Multiple Choice Question

سؤال اختياري
Quiz
🛑 CHALLENGE 1: HTML TAGS
Which tag is used to create a bulleted (unordered) list?

Think carefully before revealing the answer.

  • A) <ol>
  • B) <ul>
  • C) <li>
  • D) <list>
✓ Correct Answer: B) <ul>

Explanation: <ul> stands for Unordered List, which creates bullet points. <ol> creates numbered lists, and <li> represents the individual list items inside them.

🛑 CHALLENGE 2: FIND THE BUG
Why isn't the button turning red?

Look at the code on the right very carefully.

✓ The Bug: Missing the DOT!

The CSS selector is written as btn instead of .btn. Without the dot, CSS looks for an HTML tag called <btn> (which doesn't exist) instead of looking for the class "btn".

HTML & CSS
<!-- HTML -->
<input type="button" class="btn" value="Click Me">

/* CSS */
btn {
  background-color: red;
  color: white;
}
Knowledge Check

True or False

صح أم خطأ؟
Quiz
🛑 CHALLENGE 3: TRUE OR FALSE
"The <img> tag requires a closing tag (e.g., </img>) to work properly."
TRUE
FALSE
✓ Answer: FALSE

Explanation: The <img> tag is a "self-closing" tag. It does not wrap around any text, it only points to an image source using the src attribute. Writing </img> is incorrect HTML.
